# 故事转剧本

把小说、故事原文或故事大纲改编成可拍摄的结构化剧本。保留关键情节、因果顺序、人物关系和结局。可以把叙述和心理活动改写成可见动作、人物反应和有动机的对白，不擅自增加支线或续写。

1. 调用 get_project_script 获取剧本信息，使用 get_script_structure 核对已有分集。用户明确提供故事正文时以该正文为准，改编项目原文时按 contentReads 使用 read_script_content 读取保存的原文。只有大纲时按大纲创作。
2. 按用户指定的集数改编。未另行指定时，保留原文明示的集号及集标题；集内章号、小节和段落编号不算分集。没有分集标记的原文按一集处理。为各集规划目标、因果推进、开场承接和结尾状态，具体场次和对白交由子 Agent 创作。
3. 查询项目资产，为实际需要的人物、地点和重要道具复用或创建资产。场景包括剧情需要的过渡空间和车辆内部。依据元数据填写属性，默认设定只描述该阶段已成立的状态。
4. 调用 update_script_info 保存剧本概述、人物表和题材，再按顺序调用 save_script_episode 创建或修改用户范围内的分集。创建用剧本版本，更新用实际分集 ID 与版本，sortOrder 等于 episodeNumber，sourceType 为 1。有故事原文时，将属于该集的原文段落原样保存到 rawContent；改编内容写入场次，只有大纲时不填原文。
5. 对每个已保存分集调用 episode_script_creator，只传保存回执中的实际 scriptEpisodeId。相互独立的分集可并行，每批最多 10 个；需要承接的状态应写入对应分集大纲。
6. 查询场次，核对各集原文范围、场次、对白、场景关联和前后状态，报告已完成与未完成的数量。处理失败项前核对已保存结果，保留已完成的分集。
